## Before publishing — important
1. Replace `https://www.kumawatelectronics.in` in all canonical tags, sitemap.xml, robots.txt and LocalBusiness schema if you use a different domain. (No LocalBusiness schema has been added yet; add your verified business details before launch.)
2. Replace the SVG demo illustration and gallery placeholders with real, licensed business photos.
3. Add your verified street address, business hours, service area details, email (if any), and any confirmed warranty/charge policies.
4. Reviews page contains no fabricated testimonials. Add only genuine customer reviews with permission.
5. Test every phone number, WhatsApp link, form and navigation link on desktop and mobile.
6. The enquiry form opens WhatsApp. It does not save leads to a database and requires the visitor to press Send in WhatsApp.
7. This is a static HTML website. It is not a WordPress theme or plugin and cannot run PHP/database features.

## Test locally
Open `index.html` in a browser. For best local testing, use a simple local static server.

## Publish with GitHub Pages
- Create a public GitHub repository.
- Upload the contents of this folder (not the outer ZIP).
- Ensure `index.html` is in the repository root.
- In Settings → Pages, choose Deploy from a branch, `main`, and `/(root)`.
- Save and wait for the published URL.
